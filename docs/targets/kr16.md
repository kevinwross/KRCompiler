## Non-conforming profile

The IP16 profile is deliberately non-conforming: 16-bit `long`, no `long long`, no floating point. Code that assumes 32-bit `long` must use `int32_t`/lo-hi structures or be adapted. Every diagnostic that depends on the profile must say so.

## Code generation notes

- 16-bit little-endian; 16/32-bit instruction forms; 64 KiB address space.
- R0–R4 plus SP/SR/PC; R4 frame pointer; R0 return; R1–R3 arguments.
- Stack alignment 2 bytes; aggregates by value on the stack; varargs on the stack.
- Branch relaxation is mandatory (ADR 0003).
- Tight code-size budget: section GC and size-oriented peepholes matter.
- v1.0 compiles C only for KR16. C++ is a later decision.
