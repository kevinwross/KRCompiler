## Required before implementation

- Frozen ISA: registers, encodings, addressing modes, atomics, privilege model.
- ABI: argument/return registers, stack alignment, aggregate passing, varargs, TLS.
- Object/image format fields: target ID, relocation types, entry, layout.
- Target descriptor values and capability flags.
- A 64-bit-specific debug/frame contract.

The compiler must remain width-independent until this exists: no 32-bit pointer, `long`, or address assumptions in IR, ABI, object, or symbol code.
