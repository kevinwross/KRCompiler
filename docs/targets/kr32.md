# KR32 target profile

**Status:** Identity and data-model values are fixed by the KR32 C ABI ([ADR 0001](../decisions/0001-kr32-c-abi-freeze.md)) and descriptor schema v1 ([ADR 0002](../decisions/0002-target-descriptor-schema-freeze.md)). Register and instruction tables are completed in M2.

## Identity

| Property | Value |
|---|---|
| Family | register |
| Word/pointer width | 32 |
| Endianness | little |
| Data model | ILP32 |
| `char` | 8, signed |
| `short` / `int` / `long` / `long long` | 16 / 32 / 32 / 64 |
| `float` / `double` / `long double` | 32 / 64 / 64 (alias) |
| `size_t` / `ptrdiff_t` / `intmax_t` | 32 / 32 / 64 |
| Registers | R0–R15, F0–F15, T0–T15 |
| Fixed roles | R7 frame pointer, R11 thread pointer |
| FPU / matrix | yes / yes |
| Atomics / threads | LL/SC, cluster threads |
| EH / RTTI | v1.1 |
| TLS | static v1.0, dynamic v1.1 |
| OS services | `kr32os` host services |
| Image | KR32 native/new |

## Code generation notes

- 4/8-byte instructions; inline 11-bit immediates with extension words.
- 16/32-bit loads/stores; indexed, PC-relative, and absolute addressing.
- Branch relaxation for long displacements.
- Integer args R0–R3; FP args F0–F7; 16-byte public call alignment; `sret` above 8 bytes.
- Tile registers are caller-saved; matrix values cross calls by pointer/reference.
- The transform stack is per-thread and caller-owned.

## Capabilities

FPU, matrix/transform, atomics/LL-SC, guest threads, static/dynamic TLS, host services, file I/O, time.
