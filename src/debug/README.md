# Debug

`kdbg.cpp` implements the KDBG writer, the reader, and the text and JSON dumpers. The v1 records are frozen by [ADR 0009](../../docs/decisions/0009-kdbg-v1-freeze.md); the v1.1 scope records are added by [ADR 0052](../../docs/decisions/0052-kdbg-variable-scope-ranges.md).

Design: [docs/symbols.md](../../docs/symbols.md), `plan.md` §13.
